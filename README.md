# setup

Personal machine setup files.

Current contents:
- `ghostty_config` for Ghostty
- `.config/hypr/` for Omarchy/Hyprland monitor and workspace layout
- `.config/hypr/apps.conf` and `.config/hypr/bindings.conf` for app-to-workspace routing
- `.config/hypr/hypridle.conf` for idle lock and DPMS behavior
- `.config/waybar/config.jsonc` for workspace visibility per monitor
